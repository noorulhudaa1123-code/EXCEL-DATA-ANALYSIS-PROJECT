 Digital Banking Request Tracker
An Excel-based request management dashboard designed to track digital banking requests, monitor SLA compliance, prioritize tasks, and manage team workloads.

Project Overview
Managing digital banking requests requires proper tracking, timely responses, and clear visibility into pending and overdue tasks.
This project uses Microsoft Excel to organize requests, monitor deadlines, and present key operational metrics through a dashboard.

Key Features

Interactive Dashboard:** Summarizes request volumes, completion rates, overdue tasks, and SLA compliance.
Request Tracking:** Organizes requests by status, priority, category, and assigned team member.
SLA Monitoring:** Helps identify requests that exceed their expected completion time.
Priority Management:** Supports prioritization of requests based on urgency.
Team Workload Tracking:** Provides visibility into team assignments and workload capacity.
Automated Calculations:** Uses Excel formulas to support tracking and reporting.
Data Validation:** Uses dropdown lists to help maintain consistent data entry.
